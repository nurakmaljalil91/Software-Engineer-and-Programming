Rust is a systems programming language focused on safety, speed, and concurrency. It achieves memory safety without a garbage collector through its ownership model and compile-time borrow checker.

## Features

- **Memory Safety**: Enforced at compile-time via ownership, borrowing, and lifetime rules.
- **Zero-Cost Abstractions**: High-level idioms compile down to machine code with zero runtime overhead.
- **Fearless Concurrency**: Eliminates data races at compile time.
