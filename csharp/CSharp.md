C# is a modern, object‑oriented programming language developed by Microsoft.  It runs on the cross‑platform **.NET** runtime and is widely used for building backend services, desktop apps and games.
## Language features

- **Strong typing** – compile‑time type checking reduces runtime errors.
- **Generics** – define type‑safe data structures and algorithms (e.g., `List<T>`).
- **LINQ (Language Integrated Query)** – expressive queries over collections and databases using a fluent syntax (`Where`, `Select`, `OrderBy`).
- **Asynchronous programming** – `async`/`await` and the `Task` type make it straightforward to write non‑blocking code.
- **Pattern matching** – enhances readability when working with types and data structures.
- **Records** (C# 9) – immutable reference types ideal for value‑like entities.
## .NET runtime

- **Common Language Runtime (CLR)** – manages memory, type safety and exception handling.
- **Garbage collection** – automatically reclaims unused objects.
- **Base Class Library (BCL)** – provides collections, I/O, networking, cryptography, etc.
## Building web services

- **ASP.NET Core** – high‑performance, cross‑platform framework for building APIs and web apps.
- **Minimal APIs** – lightweight approach for quickly creating HTTP endpoints; ideal for microservices.
- **Model–View–Controller (MVC)** – separates concerns into controllers, views and models; use for more structured web apps.
- **Entity Framework Core ([[EF Core]])** – object‑relational mapper (ORM) that eliminates most data‑access boilerplate.
## Testability and maintainability

- Follow **SOLID principles** – single responsibility, open/closed, Liskov substitution, interface segregation, dependency inversion.
- Use **dependency injection** to decouple components and simplify unit testing (see `Dependency Injection.md`).
- Apply [[Clean Architecture]] and [[Domain Driven Design]] so that business logic lives in independent layers and can evolve without major rewrites.
C# and the .NET ecosystem provide a robust foundation for backend development.  Mastering the language features, frameworks and patterns will help you build reliable services that are easy to test and maintain.
